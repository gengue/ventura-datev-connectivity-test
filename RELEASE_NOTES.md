Portable Windows AMD64 connectivity diagnostic with an embedded local web interface.

- Internet DNS, HTTPS and TLS checks.
- Anonymous Hasura query for ten latest trip IDs and creation dates.
- Configurable DATEV host, port and HTTP/HTTPS; TCP and HEAD-only probes.
- Clear latency, HTTP status and error categories; visible logs and copyable report.
- No DATEV credentials, accounting extraction, synchronization or telemetry.

Run the executable inside the remote Windows desktop and keep its window open. The browser opens at http://127.0.0.1:8080/.

The executable is unsigned and subject to your company's execution policy. Actual connectivity to DATEV must be tested in your environment. An open port or HTTP response does not verify DATEV identity, licensing or data access.

Download the standalone `.exe`, or the `.zip` containing the executable and instructions. `checksums.txt` contains SHA-256 hashes for both.
